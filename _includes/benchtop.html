Technicomp Benchtop Linux · Alpha

The operating system for the technical workbench.

{% endunless %}

Conservative where regressions are expensive. Current where staleness is expensive.

{% unless include.compact %}

Benchtop Linux is a stabilized workstation rolling release derived from openSUSE Tumbleweed and MicroOS. Most of the system follows Tumbleweed, so compilers, language runtimes, libraries, firmware, and graphics stay current. The kernel and the desktop, the components most likely to disrupt a working machine when they change, move more carefully: an LTS kernel by default, and the previous upstream-supported GNOME release.

The operating system is an immutable image that arrives complete, and every update is a snapshot that can be rolled back. Users extend their own accounts, with Flatpak for applications and Homebrew for additional command-line tools, rather than modifying the system.
