Benchtop Linux is a complete Linux workstation built on openSUSE Tumbleweed and MicroOS. It keeps the development stack and underlying system current while taking a more conservative approach to the kernel and desktop, where major updates are more likely to disrupt a working machine.

The system is delivered as an immutable, transactional image with the tools, hardware support, and system integration expected on a technical workstation already in place. Applications and additional tools live in the user's profile rather than altering the operating system.

Technicomp Benchtop Linux · Alpha

The operating system for the technical workbench.

Benchtop Linux is a stabilized workstation rolling release built on openSUSE Tumbleweed and MicroOS. Most of the system stays current with Tumbleweed, while the kernel and desktop move more cautiously to reduce disruptive workstation regressions.

The operating system is a complete, immutable image. Applications and additional tools live in the user's profile through Flatpak and Homebrew rather than being layered into the system.
